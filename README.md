# Capacita a tus empleados con Microsoft 365 Copilot: Casos de uso Negocios y Ventas

Este curso ofrece una experiencia práctica para profesionales de Negocio y Ventas que buscan utilizar Microsoft 365 Copilot para identificar oportunidades, analizar información de mercado y datos de negocio, y estructurar ofertas de valor orientadas a clientes corporativos. A través de un caso transversal, los participantes utilizarán agentes como Investigador (Researcher) y Analista (Analyst), además de Copilot Chat, Copilot Notebooks, Excel y PowerPoint, para avanzar desde la comprensión del contexto de un cliente hasta la formulación, evaluación y comunicación de una oportunidad de negocio. El enfoque prioriza el uso de evidencia, la construcción de hipótesis y el criterio profesional para convertir información compleja en propuestas relevantes para el cliente.

## Lista de laboratorios

### Capítulo 1

- [Los participantes conocerán el caso del cliente corporativo ficticio y transformarán una solicitud genérica como “identifica oportunidades para este cliente” en instrucciones diferenciadas para investigar su entorno y analizar posteriormente sus datos. Definirán qué información necesitan conocer, qué evidencia esperan obtener y qué aspectos no deben asumirse sin información suficiente.](Capitulo01/README.md#los-participantes-conocerán-el-caso-del-cliente-corporativo-ficticio-y-transformarán-una-solicitud-genérica-como-identifica-oportunidades-para-este-cliente-en-instrucciones-diferenciadas-para-investigar-su-entorno-y-analizar-posteriormente-sus-datos-definirán-qué-información-necesitan-conocer-qué-evidencia-esperan-obtener-y-qué-aspectos-no-deben-asumirse-sin-información-suficiente)
  - Descripción: Conocer el caso del cliente corporativo ficticio y transformar una solicitud genérica como “identifica oportunidades para este cliente” en instrucciones diferenciadas para investigar su entorno y analizar posteriormente sus datos, definiendo la información necesaria, la evidencia esperada y los aspectos que no deben asumirse sin información suficiente.
  - Duración estimada: 6 min
- [Los participantes utilizarán Investigador (Researcher) para analizar un sector real que servirá como referencia pública para el cliente ficticio del caso. Solicitarán investigar tendencias del sector, movimientos competitivos, factores económicos, iniciativas de sostenibilidad, cambios en necesidades empresariales y otros acontecimientos que puedan afectar sus decisiones de crecimiento e inversión. El reporte deberá conservar fuentes y fechas, diferenciar evidencia de interpretación e identificar factores relevantes sin recomendar todavía productos o servicios específicos del Banco.](Capitulo01/README.md#los-participantes-utilizarán-investigador-researcher-para-analizar-un-sector-real-que-servirá-como-referencia-pública-para-el-cliente-ficticio-del-caso-solicitarán-investigar-tendencias-del-sector-movimientos-competitivos-factores-económicos-iniciativas-de-sostenibilidad-cambios-en-necesidades-empresariales-y-otros-acontecimientos-que-puedan-afectar-sus-decisiones-de-crecimiento-e-inversión-el-reporte-deberá-conservar-fuentes-y-fechas-diferenciar-evidencia-de-interpretación-e-identificar-factores-relevantes-sin-recomendar-todavía-productos-o-servicios-específicos-del-banco)
  - Descripción: Utilizar Investigador (Researcher) para analizar un sector real como referencia pública del cliente ficticio, investigando tendencias, movimientos competitivos, factores económicos, sostenibilidad, cambios en necesidades empresariales y otros acontecimientos, conservando fuentes y fechas y diferenciando evidencia de interpretación.
  - Duración estimada: 16 min
- [Los participantes analizarán un conjunto de datos completamente ficticios sobre el cliente corporativo del caso, relacionados con variables como evolución de ingresos, regiones, unidades de negocio, inversiones, crecimiento y otros indicadores relevantes. Utilizarán el agente Analista para identificar patrones, variaciones, relaciones entre variables y comportamientos que ameriten profundización. Solicitarán diferenciar los hallazgos sustentados por los datos de las hipótesis que requieren información adicional.](Capitulo01/README.md#los-participantes-analizarán-un-conjunto-de-datos-completamente-ficticios-sobre-el-cliente-corporativo-del-caso-relacionados-con-variables-como-evolución-de-ingresos-regiones-unidades-de-negocio-inversiones-crecimiento-y-otros-indicadores-relevantes-utilizarán-el-agente-analista-para-identificar-patrones-variaciones-relaciones-entre-variables-y-comportamientos-que-ameriten-profundización-solicitarán-diferenciar-los-hallazgos-sustentados-por-los-datos-de-las-hipótesis-que-requieren-información-adicional)
  - Descripción: Analizar con el agente Analista un conjunto de datos completamente ficticios del cliente corporativo para identificar patrones, variaciones, relaciones entre variables y comportamientos que ameriten profundización, diferenciando hallazgos sustentados por los datos de hipótesis que requieran información adicional.
  - Duración estimada: 13 min
- [A partir de los hallazgos obtenidos, los participantes solicitarán a Copilot formular diferentes hipótesis de necesidades u oportunidades que podrían explorarse con el cliente. Cada hipótesis deberá vincularse con la evidencia que la origina, explicar qué necesidad podría existir y señalar qué información adicional debería validarse antes de convertirla en una propuesta comercial.](Capitulo01/README.md#a-partir-de-los-hallazgos-obtenidos-los-participantes-solicitarán-a-copilot-formular-diferentes-hipótesis-de-necesidades-u-oportunidades-que-podrían-explorarse-con-el-cliente-cada-hipótesis-deberá-vincularse-con-la-evidencia-que-la-origina-explicar-qué-necesidad-podría-existir-y-señalar-qué-información-adicional-debería-validarse-antes-de-convertirla-en-una-propuesta-comercial)
  - Descripción: Formular con Copilot diferentes hipótesis de necesidades u oportunidades a partir de los hallazgos obtenidos, vinculando cada hipótesis con su evidencia de origen, la necesidad potencial y la información adicional que debe validarse antes de convertirla en una propuesta comercial.
  - Duración estimada: 7 min
- [Los participantes crearán un Copilot Notebook para reunir los principales resultados obtenidos mediante Investigador y Analista. Utilizarán el cuaderno como contexto delimitado para solicitar una síntesis que relacione tendencias externas, hallazgos derivados de los datos y necesidades potenciales del cliente, identificando coincidencias, diferencias y aspectos que requieren validación.](Capitulo01/README.md#los-participantes-crearán-un-copilot-notebook-para-reunir-los-principales-resultados-obtenidos-mediante-investigador-y-analista-utilizarán-el-cuaderno-como-contexto-delimitado-para-solicitar-una-síntesis-que-relacione-tendencias-externas-hallazgos-derivados-de-los-datos-y-necesidades-potenciales-del-cliente-identificando-coincidencias-diferencias-y-aspectos-que-requieren-validación)
  - Descripción: Crear un Copilot Notebook para reunir los principales resultados de Investigador y Analista y utilizarlo como contexto delimitado para sintetizar tendencias externas, hallazgos de datos y necesidades potenciales del cliente, identificando coincidencias, diferencias y aspectos que requieren validación.
  - Duración estimada: 8 min
- [A partir del contenido incorporado al Notebook, los participantes generarán un mapa mental para organizar visualmente los principales retos, necesidades, factores externos y oportunidades identificados. Revisarán la estructura obtenida para identificar relaciones entre necesidades, hallazgos y oportunidades, y determinar cuáles ameritan continuar hacia una etapa de evaluación.](Capitulo01/README.md#a-partir-del-contenido-incorporado-al-notebook-los-participantes-generarán-un-mapa-mental-para-organizar-visualmente-los-principales-retos-necesidades-factores-externos-y-oportunidades-identificados-revisarán-la-estructura-obtenida-para-identificar-relaciones-entre-necesidades-hallazgos-y-oportunidades-y-determinar-cuáles-ameritan-continuar-hacia-una-etapa-de-evaluación)
  - Descripción: Generar a partir del Notebook un mapa mental que organice visualmente los principales retos, necesidades, factores externos y oportunidades identificados, revisando sus relaciones para determinar cuáles ameritan continuar hacia una etapa de evaluación.
  - Duración estimada: 7 min
- [Los participantes seleccionarán una de las oportunidades identificadas y utilizarán Copilot en modo Plan para estructurar en un libro nuevo un instrumento de análisis con los supuestos y variables necesarias para evaluarla. Construirán distintos escenarios ilustrativos (por ejemplo, conservador, base y expansivo) utilizando exclusivamente información ficticia y supuestos explícitos.](Capitulo01/README.md#los-participantes-seleccionarán-una-de-las-oportunidades-identificadas-y-utilizarán-copilot-en-modo-plan-para-estructurar-en-un-libro-nuevo-un-instrumento-de-análisis-con-los-supuestos-y-variables-necesarias-para-evaluarla-construirán-distintos-escenarios-ilustrativos-por-ejemplo-conservador-base-y-expansivo-utilizando-exclusivamente-información-ficticia-y-supuestos-explícitos)
  - Descripción: Seleccionar una oportunidad identificada y utilizar Copilot en modo Plan para estructurar en un libro nuevo un instrumento de análisis con los supuestos y variables necesarios para evaluarla, construyendo escenarios ilustrativos con información ficticia y supuestos explícitos.
  - Duración estimada: 8 min
- [Utilizando Copilot en modo Edición, los participantes profundizarán sobre el instrumento creado, incorporarán cálculos y comparaciones entre escenarios y generarán una visualización que permita identificar cómo cambian los resultados ante diferentes supuestos. Finalmente, solicitarán identificar qué variables tienen mayor incidencia y cuáles requieren validación antes de presentar la oportunidad al cliente.](Capitulo01/README.md#utilizando-copilot-en-modo-edición-los-participantes-profundizarán-sobre-el-instrumento-creado-incorporarán-cálculos-y-comparaciones-entre-escenarios-y-generarán-una-visualización-que-permita-identificar-cómo-cambian-los-resultados-ante-diferentes-supuestos-finalmente-solicitarán-identificar-qué-variables-tienen-mayor-incidencia-y-cuáles-requieren-validación-antes-de-presentar-la-oportunidad-al-cliente)
  - Descripción: Profundizar con Copilot en modo Edición sobre el instrumento creado, incorporando cálculos, comparaciones entre escenarios y una visualización que muestre cómo cambian los resultados ante diferentes supuestos, e identificando las variables de mayor incidencia y las que requieren validación.
  - Duración estimada: 8 min
- [Con los resultados obtenidos, los participantes solicitarán a Copilot estructurar una propuesta preliminar que relacione necesidad detectada + evidencia + oportunidad + valor esperado para el cliente, evitando presentar como hechos los supuestos utilizados durante el análisis.](Capitulo01/README.md#con-los-resultados-obtenidos-los-participantes-solicitarán-a-copilot-estructurar-una-propuesta-preliminar-que-relacione-necesidad-detectada-evidencia-oportunidad-valor-esperado-para-el-cliente-evitando-presentar-como-hechos-los-supuestos-utilizados-durante-el-análisis)
  - Descripción: Estructurar con Copilot una propuesta preliminar que relacione necesidad detectada, evidencia, oportunidad y valor esperado para el cliente, evitando presentar como hechos los supuestos utilizados durante el análisis.
  - Duración estimada: 4 min
- [Los participantes solicitarán a Copilot preparar un breve speech ejecutivo para presentar la oportunidad seleccionada ante el cliente. La conversación deberá partir de la comprensión de sus necesidades y de la evidencia analizada antes de introducir la propuesta de valor.](Capitulo01/README.md#los-participantes-solicitarán-a-copilot-preparar-un-breve-speech-ejecutivo-para-presentar-la-oportunidad-seleccionada-ante-el-cliente-la-conversación-deberá-partir-de-la-comprensión-de-sus-necesidades-y-de-la-evidencia-analizada-antes-de-introducir-la-propuesta-de-valor)
  - Descripción: Preparar con Copilot un breve speech ejecutivo para presentar la oportunidad seleccionada ante el cliente, partiendo de la comprensión de sus necesidades y de la evidencia analizada antes de introducir la propuesta de valor.
  - Duración estimada: 5 min
- [A partir de los resultados del caso, los participantes utilizarán Copilot en PowerPoint para generar una presentación ejecutiva breve que sintetice contexto del cliente, necesidad identificada, evidencia relevante, oportunidad propuesta, escenarios analizados y próximos pasos. Se revisará la estructura generada para asegurar que la presentación diferencie claramente hechos, hipótesis y supuestos.](Capitulo01/README.md#a-partir-de-los-resultados-del-caso-los-participantes-utilizarán-copilot-en-powerpoint-para-generar-una-presentación-ejecutiva-breve-que-sintetice-contexto-del-cliente-necesidad-identificada-evidencia-relevante-oportunidad-propuesta-escenarios-analizados-y-próximos-pasos-se-revisará-la-estructura-generada-para-asegurar-que-la-presentación-diferencie-claramente-hechos-hipótesis-y-supuestos)
  - Descripción: Utilizar Copilot en PowerPoint para generar una presentación ejecutiva breve que sintetice contexto del cliente, necesidad identificada, evidencia relevante, oportunidad propuesta, escenarios analizados y próximos pasos, asegurando la diferenciación entre hechos, hipótesis y supuestos.
  - Duración estimada: 8 min
- [Los participantes solicitarán a Copilot asumir el rol de un directivo del cliente corporativo ficticio. Durante un breve juego de roles, Copilot cuestionará los supuestos, beneficios, diferenciadores y viabilidad de la propuesta. El participante responderá utilizando la evidencia obtenida durante el caso y, al finalizar, Copilot identificará las preguntas que fueron respondidas adecuadamente y aquellas para las que todavía sería necesario obtener información adicional.](Capitulo01/README.md#los-participantes-solicitarán-a-copilot-asumir-el-rol-de-un-directivo-del-cliente-corporativo-ficticio-durante-un-breve-juego-de-roles-copilot-cuestionará-los-supuestos-beneficios-diferenciadores-y-viabilidad-de-la-propuesta-el-participante-responderá-utilizando-la-evidencia-obtenida-durante-el-caso-y-al-finalizar-copilot-identificará-las-preguntas-que-fueron-respondidas-adecuadamente-y-aquellas-para-las-que-todavía-sería-necesario-obtener-información-adicional)
  - Descripción: Solicitar a Copilot asumir el rol de un directivo del cliente corporativo ficticio y realizar un breve juego de roles en el que se cuestionen supuestos, beneficios, diferenciadores y viabilidad de la propuesta, respondiendo con la evidencia obtenida y detectando la información adicional aún necesaria.
  - Duración estimada: 7 min
